Monkey and Hunter Experiment

Physics Introduction

The Monkey and Hunter is a classic thought experiment in physics illustrating the independence of horizontal and vertical motion. A hunter aims a gun directly at a monkey hanging from a tree branch. The exact moment the gun is fired, the monkey lets go of the branch and begins to fall.

Because gravity accelerates all objects downwards at the exact same rate (approx. 9.8 m/s²) regardless of their horizontal velocity, both the projectile and the monkey fall equal vertical distances from their initial un-accelerated paths in the same amount of time. Since the gun was aimed directly at the monkey, the bullet's path drops identically to the monkey's position, guaranteeing a mid-air collision—provided the bullet is fired fast enough to reach the monkey before they both hit the ground.

Focus: In a gravitational field, all objects accelerate downwards at the exact same rate regardless of their horizontal speed. If a gun is fired horizontally at the exact moment a target drops from the same height, the bullet and the target will fall equal vertical distances in the same amount of time, resulting in a mid-air collision.

Experimental Setup

  • Hunter's Gun: NERF Slyshot with cotton bullet to ensure safety. One ESP32-S3 Mini with a photo gate is attached to the barrel of the gun. When the cotton bullet passes through, it triggers the drop of the monkey.
  • Monkey: Puffy toy hanging on an electromagnet connected to the secondary side of a Photo-coupler. The drop is triggered by an output signal attached to a secondary ESP32-S3 Mini.
  • Range: 3 meters to 10 meters.
  • Communication hardware: ESP32-S3 Mini
  • Communication protocol: ESP-NOW

Source Code

Gun ESP32 (gun.cpp)

#include <Arduino.h>
#include <WiFi.h>
#include <esp_now.h>

// GPIO pin for photogate sensor
#define PHOTOGATE_PIN 4

// MAC address of Station 2 (replace with actual MAC from Station 2)
uint8_t station2MAC[] = {0x24, 0x6F, 0x28, 0xAA, 0xBB, 0xCC};

// Structure for sending data
typedef struct struct_message {
    char msg[32];
} struct_message;

struct_message myData;

// Callback when data is sent
void onDataSent(const uint8_t *mac_addr, esp_now_send_status_t status) {
    Serial.print("Send Status: ");
    Serial.println(status == ESP_NOW_SEND_SUCCESS ? "Success" : "Fail");
}

void setup() {
    Serial.begin(115200);

    pinMode(PHOTOGATE_PIN, INPUT_PULLUP);

    // Init WiFi in STA mode
    WiFi.mode(WIFI_STA);
    Serial.print("Station 1 MAC: ");
    Serial.println(WiFi.macAddress());

    // Init ESP-NOW
    if (esp_now_init() != ESP_OK) {
        Serial.println("Error initializing ESP-NOW");
        return;
    }

    esp_now_register_send_cb(onDataSent);

    // Add Station 2 as peer
    esp_now_peer_info_t peerInfo = {};
    memcpy(peerInfo.peer_addr, station2MAC, 6);
    peerInfo.channel = 0;
    peerInfo.encrypt = false;

    if (esp_now_add_peer(&peerInfo) != ESP_OK) {
        Serial.println("Failed to add peer");
        return;
    }
}

void loop() {
    static bool lastState = HIGH;
    bool currentState = digitalRead(PHOTOGATE_PIN);

    // Trigger when photogate changes from HIGH to LOW
    if (lastState == HIGH && currentState == LOW) {
        strcpy(myData.msg, "TRIGGER");
        esp_err_t result = esp_now_send(station2MAC, (uint8_t *)&myData, sizeof(myData));
        if (result == ESP_OK) {
            Serial.println("Message sent to Station 2");
        } else {
            Serial.println("Error sending message");
        }
    }
    lastState = currentState;
}

Monkey Drop ESP32 (drop.cpp)

#include <Arduino.h>
#include <WiFi.h>
#include <esp_now.h>

// GPIO pin for optocoupler input
#define OPTOCOUPLER_PIN 5
// GPIO pin for output trigger
#define OUTPUT_PIN 2

// Structure for receiving data
typedef struct struct_message {
    char msg[32];
} struct_message;

struct_message incomingData;

// Callback when data is received
void onDataRecv(const uint8_t *mac_addr, const uint8_t *data, int len) {
    memcpy(&incomingData, data, sizeof(incomingData));
    Serial.print("Received message: ");
    Serial.println(incomingData.msg);

    if (strcmp(incomingData.msg, "TRIGGER") == 0) {
        digitalWrite(OUTPUT_PIN, HIGH);
        delay(500); // Pulse duration
        digitalWrite(OUTPUT_PIN, LOW);
    }
}

void setup() {
    Serial.begin(115200);

    pinMode(OPTOCOUPLER_PIN, INPUT_PULLUP);
    pinMode(OUTPUT_PIN, OUTPUT);
    digitalWrite(OUTPUT_PIN, LOW);

    // Init WiFi in STA mode
    WiFi.mode(WIFI_STA);
    Serial.print("Station 2 MAC: ");
    Serial.println(WiFi.macAddress());

    // Init ESP-NOW
    if (esp_now_init() != ESP_OK) {
        Serial.println("Error initializing ESP-NOW");
        return;
    }

    esp_now_register_recv_cb(onDataRecv);
}

void loop() {
    // Station 2 is passive — no loop actions needed
}
